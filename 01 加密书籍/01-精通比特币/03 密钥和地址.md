## 本章节的主旨

在对比特币有了初步了解之后，从本章开始，我们将深入比特币的所有权机制：如何确定资产归属、如何管理所有权，以及如何安全地转移所有权。本章聚焦于密码学基础，包括椭圆曲线密码学、哈希函数和数字签名，并详细讲解私钥、公钥与地址之间的单向派生关系。我们将看到私钥如何通过椭圆曲线生成公钥，公钥又如何经过哈希和编码生成地址。理解这些基本构建块，是理解比特币交易、钱包和整个网络安全模型的起点，也是逐步摸清比特币这台庞大机器如何运转的关键一步。

## 本章节大纲

私钥 ➡️ 公钥 ➡️ 地址

## 关键定义

1. 私钥：控制比特币的唯一凭证，本质是一串随机数，其大小介于在 1 到 2^256 之间。略小于2^256

2. 公钥：由私钥推导，用于生成地址和验证签名。K = k（私钥） × G

3. 地址：由公钥或脚本经过哈希和编码得到的收款标识。链上真正记录的是脚本，地址只是方便用户使用。

4. 公钥到地址的过程

   最初地址：公钥 → SHA256 → RIPEMD160 → 公钥哈希 → 加版本前缀 → 双 SHA256 取前 4 字节作校验和 → Base58Check 编码 → 地址（1...）
   
   SegWit/Taproot 地址：公钥哈希或调整公钥 → Bech32/Bech32m 编码 → bc1q... / bc1p...

6. 常见地址类型

| 地址类型 | 主网前缀 | 编码方式 | 锁定脚本 / 含义 | 特点 |
| :--- | :--- | :--- | :--- | :--- |
| **P2PKH** | `1...` | Base58Check | `OP_DUP OP_HASH160 <公钥哈希> OP_EQUALVERIFY OP_CHECKSIG` | 最早期地址类型，兼容性好，但手续费相对较高 |
| **P2SH** | `3...` | Base58Check | `OP_HASH160 <脚本哈希> OP_EQUAL` | 常用于多签、嵌套 SegWit；花费时需要提供 redeem script |
| **P2WPKH** | `bc1q...` | Bech32 | `OP_0 <20字节公钥哈希>` | 原生隔离见证 v0，手续费低，地址较短 |
| **P2WSH** | `bc1q...` | Bech32 | `OP_0 <32字节脚本哈希>` | 原生隔离见证 v0，适合复杂脚本、多签；花费时需要提供 witness script |
| **P2TR** | `bc1p...` | Bech32m | `OP_1 <32字节调整后公钥>` | Taproot 地址，支持 Schnorr 签名和 MAST，隐私与效率更好 |

## 疑问及解答

1. Base58check ，bech32 和 bech32m 都是编码方式，他们有什么不同，为什么会从 base58check 一直更换到 bech32m 呢？

| 特性 | Base58Check | Bech32 (BIP 173) | Bech32m (BIP 350) |
| :--- | :--- | :--- | :--- |
| **主要应用** | P2PKH (`1...`), P2SH (`3...`) | SegWit v0 (`bc1q...`) | SegWit v1+ / Taproot (`bc1p...`) |
| **字符集** | 58个字符，大小写混合 | 32个字符，全小写 | 32个字符，全小写 |
| **大小写规则** | 大小写敏感 | 不敏感（全小写或全大写，不可混用） | 不敏感（全小写或全大写，不可混用） |
| **校验和** | 双SHA-256，前4字节 | BCH码，6字符 | BCH码，6字符（常量不同） |
| **错误检测** | 只能检测错误，无法定位 | 能检测并定位最多4个字符错误 | 能检测并定位错误，且修复了插入漏洞 |
| **二维码** | 体积大（需字节模式） | 体积小（可用字母数字模式） | 体积小（可用字母数字模式） |


## 本章节评价

通过本章的学习，我理解了比特币最基础的构建块——椭圆曲线密码学、哈希函数和数字签名，以及私钥、公钥与地址之间的单向派生关系。同时，我也认识到现代钱包并不是单独保存一堆私钥，而是通过 BIP32/BIP39 从一个种子派生出整棵密钥树，只需备份一次助记词就能恢复所有地址。在地址层面，从 Base58Check 到 Bech32，再到 Bech32m，编码方式的演进不仅提升了错误检测能力和二维码效率，也在安全性和隐私性上不断优化。此外，公钥压缩、多种地址类型（P2PKH、P2SH、P2WPKH、P2WSH、P2TR）以及地址不是账户、余额是 UTXO 总和这些概念，也让我对比特币的所有权模型有了更清晰的认识。这让我看到，比特币的地址和密钥体系并非一成不变，而是在实践中不断打磨，兼顾易用、安全与未来扩展。
